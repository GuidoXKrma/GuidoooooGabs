PUBLICAR ESTE PROYECTO EN GITHUB
1. Abre https://github.com/new e inicia sesión.
2. Nombre sugerido: mini-proyecto-monolito-microservicios. Si el profesor necesita abrir el enlace, elige Public.
3. Crea el repositorio vacío (no agregues README ni .gitignore).
4. Descomprime este ZIP y abre una terminal en la carpeta del proyecto. Ejecuta:
   git init
   git add .
   git commit -m "Mini proyecto monolito y microservicios"
   git branch -M main
   git remote add origin https://github.com/TU_USUARIO/mini-proyecto-monolito-microservicios.git
   git push -u origin main
5. Cambia TU_USUARIO por tu usuario real de GitHub. GuidoGabrielGG es el usuario WSL que indicaste y puede ser distinto del usuario de GitHub.
6. Comparte el enlace del repositorio creado.

No compartas contraseñas ni tokens. El repositorio remoto requiere iniciar sesión y autorizar la publicación.
